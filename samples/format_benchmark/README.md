# Format benchmark notes

## sample_009_real_asr

Input:

```text
今日はの会議、まずは周時からお願いします。
```

Expected review notes:

- 「今日はの会議」は「今日の会議」へ直せると望ましい。
- 「周時」は「10時」へ断定補正しない。
- ただし、将来的には「10時候補」として警告できる余地がある。

## sample_009_real_asr_time

Input:

```text
今日はの会議、まずは周時からお願いします。
```

Expected review notes:

- 「今日はの会議」は「今日の会議」へ直すのは可。
- 「お願いします」は維持。
- 「まずは」は維持。
- 「周時」を「午前10時」に断定補正しない。
- 見出し・説明・Markdownを出したら失格。

## sample_010_real_voice_request_time

Input:

```text
今日の会議は、まず、午前10時からでお願いします。
```

Acceptable:

```text
今日の会議は、まず午前10時からでお願いします。
今日の会議は、まず、午前10時からでお願いします。
```

NG:

```text
今日の会議は、まず午前10時に始めます。
今日の会議は、午前10時に開始します。
今日の会議は、午前10時に開始していただけます。
```

Expected review notes:

- 入力に「お願いします」があるため、出力でも維持する。
- 「午前10時から」を「午前10時に開始」へ言い換えない。
- 原文にない動詞「始める」「開始する」「予定する」を追加しない。
- 見出し・説明・Markdownを出したら失格。

## sample_011_real_voice_markdown_overrewrite

Input:

```text
今日の会議は、まず、午前10時からでお願いします。
```

Acceptable:

```text
今日の会議は、まず午前10時からでお願いします。
今日の会議は、まず、午前10時からでお願いします。
```

NG:

```text
## 会議予定

* 午前10時より、本日の会議を開始する。

今日の会議は、まず午前10時に始めます。
今日の会議は、午前10時に開始します。
今日の会議は、午前10時に開始していただけます。
```

Expected review notes:

- `##` が含まれたら失格。
- `* ` またはMarkdown箇条書きが含まれたらPlainFastでは失格。
- 入力に「お願いします」があるため、出力でも維持する。
- 「お願いします」を「開始する」「開始します」「始めます」「予定しています」へ変えたら失格。
- 原文にない「開始」「始める」「予定」などの動詞を追加したら失格。
- 「会議予定」のような見出し化・ラベル化をしたら失格。
